this project aims to create an music using quantum randomness
the library utilised include qiskit and qiskit-aer to simulate an quantum circuit which generates an random bits output which is then converted to an integer 
this integer acts as an index which is then used to play the key as we predefined those notes.
i used midiutil module to convert the generated music notes to a midi file which can be then played using a midifile player
first i have tested the program only  using piano and for only specified note duration then i have optimised the code and added different instruments that can play any duration of notes
i have included various instruments like piano violin and flute in this program to create a random music generated using the simulated quantum circuit
this is an application of quantum random number generator [QRNG]
i am planning to further optimise it into an fully functional website which can gain input from the user the choices of instruments and generate the random music according to the needs of the user
through this project i want to display my understanding on backend development, python and API integrations
